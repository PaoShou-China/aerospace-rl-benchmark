# 原计划的投影误差界修正

原 PLAN_ZH.md 中的模板为 rho*||A(I-P)|| + 0.5*H*rho² + e_model + e_numeric。

若比较基准是投影子空间中**非线性原函数**的最小值，需要同时计入 R(eta) 与 R(P eta) 的 Taylor 余项。两个点都在半径 rho 的球内时，安全的保守模板为：

**rho*||A(I-P)|| + H*rho² + e_model + e_numeric。**

H 必须覆盖整个声明区域的白化坐标 Hessian 算子范数。若基准改为仿射近似的下界，单个 0.5*H*rho² 才适用。模型与数值项需独立覆盖完整比较误差；接触切换和投影内最小值也各自需要有效界。

独立审查给出一个可嵌入 87 维的二维二次反例：m(z)=0.65-z1/3+0.5*zᵀHz，其中 H=[[1/sqrt(3),-sqrt(2/3)],[-sqrt(2/3),-1/sqrt(3)]]，||H||=1、rho=1、P=diag(1,0)。投影内最小值为 0.5537749551；完整球内 z=(1/sqrt(3),sqrt(2/3)) 的余量为 -0.0235753141。旧模板错误给出条件通过，修正后输出证据不足。

回归测试已先复现失败再通过；证据见 reports/remainder_red.log 与 remainder_green.log。原始设计文档保持原样，本更正优先。实际候选检查从未启用条件通过，G2 仍未完成。
