# 初始化与课程统计修正后的训练实验

本次实验只修改 `splits`，从头训练 1000 轮，不加载旧策略或旧初始化缓存。
1024 个并行环境，每轮 128 步，共 131,072,000 条环境转移；种子为 7。
保留现有 QuadX 动力学、动作范围、奖励、四门训练任务、网络及 PPO 超参数。

## 本次改动

| 文件 | 改动 |
| --- | --- |
| `initial_state_buffer.py` | 用最近 1024 个已结束回合的实际成功比例替代按时间步更新的 EMA；保存窗口历史及实际重置/回放计数 |
| `env.py` | 记录窗口成功率、窗口样本数、缓存实际使用次数及累计使用比例；沿用已经修正的偏航初始化 |
| `evaluation.py` | 支持随机四门与固定起点完整七门评估；只加载模型，不恢复训练缓存或 RNG；增加逐门通过与失败统计 |
| `ppo.py` | 增加可选 checkpoint 回调；最终报告包含课程窗口和实际回放计数 |
| `run_evaluation_experiment.py` | 隔离进程评估、旧模型参照、未训练参照、定期验证、最佳模型保存及状态记录 |
| `.gitignore` | 忽略 `experiments/` 中的模型、日志和编译缓存 |

## 课程条件

- 最近 1024 个已结束回合，每个回合等权。同一步结束的回合按环境编号加入窗口。
- 至少有 64 个窗口样本，缓存中至少有 128 条状态，窗口成功率达到 60% 时可用。
- 可用时每次重置有 50% 概率从缓存采样。阈值仍会动态判断，未增加锁定或滞回。
- 未完成回合不进入窗口，因此短期结束时间偏差仍可能存在；修正的是样本权重。
- 旧 checkpoint 没有窗口历史：读取时保留缓存飞行状态，但清空成功窗口并重新暖启动，不把旧 EMA 当作新统计。
- 本实验使用新模型，不依赖旧 checkpoint 兼容路径。

## 评估协议

每种协议使用种子 7、17、27，每个种子 64 个环境，各统计第一个完整回合。

1. 随机连续四门：使用训练的赛段位置扰动及正确朝向，禁用课程缓存，以保证各模型可比较。
2. 固定起点完整七门：起点 `[-1.275, 2.975, 2.365]`，朝向第一门，无位置扰动。

每个回合最多 20 秒。记录逐门被尝试次数、通过次数、条件通过率，以及以该门为目标时
发生的撞门、触地、越界和超时次数。失败归属的是当时目标门，不代表实际撞击的门编号。
未到达的门不计作尝试；如果没有尝试，该门通过率为 null。

训练前：在当前相同初始化下重新评估旧 2000/4000 轮模型，并评估真正未训练的新策略。
训练中：模型文件 `model_200.pt`、`model_400.pt`、`model_600.pt`、`model_800.pt`
保存后评估（对应完成 201、401、601、801 轮），训练正常结束后评估 1000 轮模型。
每次验证都在独立子进程中运行，不消耗训练进程 RNG 或修改训练观测归一化。
按完整赛道完赛率、通过门数、四门成功率、四门通过门数依次选择 `best.pt`。

这是一组组合修正实验，不能单独证明哪项修正导致变化。旧模型参照的预算和初始化历史不同。
固定起点副本不是不同初始状态；定期选择模型使用的种子属于验证集，不是独立最终泛化测试。
控制台原有 `Mean episode success_rate` 仍是时间步均值；判断课程状态请看
`curriculum_success_window_rate`，判断测试表现请看按回合统计的评估 JSON。

## 运行及产物

```powershell

E:\miniconda\envs\arbnhmk\python.exe -u environments/multirotor/splits/run_evaluation_experiment.py
```

冒烟测试运行 2 轮、8 个环境，使用缩短的回合期限，只验证流程，不衡量策略能力。
每种模式的目录都拒绝覆盖已有实验，不可直接重复启动。

正式产物目录：`splits/experiments/window1024_seed7_1000/`。

- `status.json`：当前阶段；失败时记录异常。
- `manifest.json`、`source_snapshot/`：训练设置及启动时源代码。
- `comparison.json`、`evaluations/`：旧模型、未训练策略与各训练阶段的分层评估。
- `training_metrics/`：数量加权的累计成功次数，以及窗口率、缓存使用次数。
- `best.pt`、`best.json`：验证表现最佳的训练模型及其轮数。
- `checkpoint.pt`、`model_*.pt`：最终及定期存档；中途终止时应按存档轮数恢复。

本脚本不会自动恢复中断实验。所有模型、日志、配置及编译缓存均写在 `splits` 内。

## 后续实验：预瞄第五门，第四门结束

2026-10-28 增加 `continue_lookahead_experiment.py`，从上述实验的最终 1000 轮
checkpoint 再训练 1000 轮，累计 2000 轮，产物写入 `experiments/lookahead5_resume_2000/`。
原模型文件保留。正式训练前会在新观测协议下评估原模型；每约 200 轮及结束时再评估。

`env.py` 的唯一任务行为变化是训练片段末端的预瞄：

| 已通过本回合门数 | 两个门槽位 |
| --- | --- |
| 0 | 第一门、第二门 |
| 1 | 第二门、第三门 |
| 2 | 第三门、第四门 |
| 3 | 第四门、第五门（由赛道顺序推得，必要时从 Gate7 环回 Gate1） |
| 4 | 回合成功结束；终止观测的门槽清零，然后重置 |

第五门不加入 `gate_ids` 的任务目标序列，不参与四门完成条件；奖励、动力学和观测维度保持原样。
完整七门测试的观测构造不变。随机四门评估采用新的预瞄规则，因此不能直接把新协议的
基线成绩与旧协议下的 85.42% 当作训练带来的提升。

本次恢复网络、优化器、归一化、课程缓存和随机数状态；轨迹在加载后重新初始化。
`--smoke` 会复制源模型到独立目录，真实续训 1 轮，并用缩短的测试验证存档/评估链路。
正式实验只读取原 1000 轮 checkpoint，不使用冒烟更新后的模型。
