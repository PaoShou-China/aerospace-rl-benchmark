# 基于 MoE 基础策略的火箭着陆算法研究

本工作基于原仓库的 **PDG 控制器示范 → BC 预训练 → PPO 训练** 流程，完成了训练实现修复、奖励与参数实验、分阶段策略网络和 DAgger 训练，并进一步加入专家选择及局部反馈修复。当前最高本机开发记录为 **444/512（86.72%）**。

[English](README.md) · [详细技术报告](technical_report.md)

这里的 MoE 指按飞行阶段选择动作头的策略网络。本文说明相对原项目的具体工作和最优记录对应方案。结果快照日期：2026-10-23。

## 原项目提供了什么

以提交 `39e6bb6fd5d0f5432f7405a76946938a469492ce` 为起点，原项目已经提供：

- **仿真任务**：Genesis 火箭动力学、30 维观测、7 维动作、初始分布及着陆判定。
- **传统控制器**：PDG 着陆控制器，可直接控制火箭，也可作为学习策略的教师。
- **学习流程**：采集教师示范进行 BC，再用 RSL-RL PPO 训练单个 Flash 残差策略网络；另有 FlashSAC 算法实现。
- **训练基础设施**：GPU 批量仿真、检查点保存和通用评估入口。

上述环境、教师控制器、PPO/FlashSAC 算法基础均沿用原项目。我们的新增工作集中在下面几项。

## 我们在此基础上做了什么

| 工作 | 原来的方式 | 我们的具体改动及作用 |
| --- | --- | --- |
| **补齐着陆学习数据** | BC 每个环境采集 512 步教师示范；本机复测中没有采到接触平台的片段 | 将示范采集扩展到完整 1200 步，并加入 **DAgger**：让学生访问真实状态，再由原 PDG 标注动作、聚合重训，覆盖学生自己产生的偏差 |
| **重做策略表示与结构** | 单个 Flash 残差网络处理整个着陆过程 | 从原观测构造 33 个状态特征，采用 **共享网络＋高空、接近、近地三个动作头**；连续动作使用加权回归，点火增加分类损失。与 DAgger 联合训练得到 **79.10%**，后续专家续训达到 **84.38%** |
| **修复并实践原 PPO 路线** | 原 Flash 网络在有梯度的前向中投影参数，采样与更新可能得到不同动作概率；使用固定奖励和训练配置 | 将投影移到优化器更新后；开展奖励缩放、势函数／事件奖励、学习率、GAE、探索噪声、参考 KL、近地专家更新等实验。实现和实验均已完成，**尚未证明单靠这些调整优于最强起点** |
| **学习如何组合已训练策略** | 一次运行使用一个策略 | 将我们训练得到的 DAgger 和 PPO 专家冻结，用初态门控预测两者的成功差，选择一个执行整回合；组合策略记录为 **85.55%** |
| **针对残余失败学习局部修复** | 没有学习何时调用短时修复控制的机制 | 搜索介入时机、持续时长、点火模式和 12 个反馈参数，得到 10 个程序，再训练状态门控调用；最高记录为 **86.72%** |
| **补齐实验运行与比较工具** | 已有 GPU 批量训练及通用评估 | 增加配置化实验、CPU 多进程采样、GPU 动态分块，以及固定首回合评测、逐样本对比和源码／预算记录，使不同方案能够追溯比较 |

**79.10% 是我们完成分阶段网络＋DAgger 后的阶段性成果，不是原仓库自带模型的成功率。** 原代码的小规模 CPU 复跑为 0/512，但仅使用默认在线预算的约 1.6%，因此不能将它和后续不同数据量、结构及预算的方案当作等预算提升对照。原仓库 README 的 66.8% 则属于传统 PDG 控制器，评测窗口也不同。

## 当前提交主线与效果

最优记录对应的完整路线是：

```text
原 PDG 教师
  → 完整着陆示范＋DAgger 数据聚合
  → 分阶段策略网络及后续 DAgger／PPO 专家训练
  → 初态专家选择
  → 状态触发的短时反馈修复
```

同一 CPU、float32、固定 512 回合开发协议下，主线的阶段性记录为：

**分阶段 DAgger r3：405/512（79.10%） → 专家续训：432/512（84.38%） → 专家组合：438/512（85.55%） → 局部修复：444/512（86.72%）。**

这条链展示方案的发展过程，各阶段训练预算不同，不能解释为每个组件的独立增益。最后一步相对重新评测的父策略净增加 6 次成功，即 **+1.17 个百分点**；增益尚未证明稳健，部分结局变化发生在未介入的回合，存在仿真批次耦合迹象。

推理时先选择一个冻结专家，再根据当前观测决定是否介入；每回合最多执行一次有限时长修复，之后回到专家。搜索和教师标注均在训练阶段进行，在线输出仍为原环境的 7 维动作。

成功率沿用原环境“回合中曾满足着陆条件”的口径。最高记录对应模型的**终局严格稳定为 0/512**，86.72% 因而不等于最终稳定着陆率。当前尚未达到 95% 或 99%。

## 最小提交范围

策略推理核心为四个模块：

| 模块 | 作用 |
| --- | --- |
| [phase_policy.py](phase_policy.py) | 两个专家共用的分阶段策略结构 |
| [expert_router.py](expert_router.py) | 初态专家选择与回合状态管理 |
| [feedback_program.py](feedback_program.py) | 有限时长反馈程序、观测特征及动作约束 |
| [repair_policy.py](repair_policy.py) | 修复门控与在线策略组合 |

本包包含最优记录对应的推理代码、完整模型、在模型内置冻结父策略基础上重新训练反馈修复的入口，以及独立评测入口。历史 MoE／DAgger／PPO 专家训练及其他探索仅作为研究过程记录，不包含完整的历史调参流水线。

**版本要求：本包保留实测模型“距着陆面 150 米以下才允许触发修复”的限制，以及训练保持样本的相同高度筛选规则。** 配套模型与原始实测模型哈希相同。

下表仅概括主要路线。CPU 完整开发评测与上文使用相同的 4×128 分组；128 回合初筛、96 对确认和 GPU 成绩分别标注。

| 路线 | 已完成结果 | 简要结论 |
